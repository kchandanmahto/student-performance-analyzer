## About StudentIQ

**StudentIQ** is an intelligent student performance analytics platform developed under the **CKMHTO.AI** brand.

It transforms student academic data into meaningful insights through data analysis, visualization, and machine learning.

The platform helps explore academic performance patterns, understand contributing factors, and estimate student marks using predictive models.

## Core Capabilities

| Module | Description |
|---|---|
| Data Management | Student dataset collection and cleaning |
| Data Analysis | Exploratory Data Analysis (EDA) |
| Feature Engineering | Creating meaningful academic indicators |
| Data Processing | Preparing data for machine learning |
| Predictive Analytics | Student marks prediction |
| Model Evaluation | Comparing machine learning performance |
| Interactive Dashboard | Visual analytics through Streamlit |

## Machine Learning Models

StudentIQ currently explores the following regression models:

- Linear Regression
- Random Forest Regressor
